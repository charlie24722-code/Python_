ventas = [3, 8, 1, 9, 4]
print(sum(v for v in ventas if v > 3), ventas[1:4])

8 + 9 + 4 = 21; slice de 1 a 3.

(Python) ¿Qué devuelve f(4)?

def f(n):
    if n == 0:
        return 1
    return 2 * f(n - 1)

2 × 2 × 2 × 2 × 1 = 16.

(Python) ¿Qué imprime?

stock = {"A": 5}
stock["B"] = stock.get("B", 0) + 3
stock["A"] -= 2
print(stock)

get da 0 para B; A baja a 3.

except ValueError:
    x = -1
else:
    x = x * 2
print(x)

Simulacro práctico (2 horas)

El mismo problema de negocio, primero en Python (con archivos, diccionarios y clases) y luego en C#. Es exactamente el tipo de “equivalencia entre lenguajes” que evalúa el Final.

P1 · Suscripciones SaaS en Python (S7 + S8)

clases + JSON + diccionarios · ★★★★

Una plataforma cobra planes básico ($9.99) y pro ($24.99) por mes; desde 12 meses activos el cliente recibe 15 % de descuento. Carga las suscripciones desde JSON (si el archivo no existe, lista vacía), calcula el ingreso mensual y cuenta clientes por plan. Un plan desconocido lanza ValueError.

Tu programa debe cumplir estos casos de prueba:

DatoEsperado
Ana, pro, 14 meses$21.24
Luis, básico, 3 meses$9.99
Eva, pro, 2 meses$24.99
Ingreso mensual$56.22
Clientes por plan{'pro': 2, 'basico': 1}
Sin archivo[]
Pista

Clase con validación en __init__; función cargar con try/except FileNotFoundError; acumular por clave para contar planes.

Solución
import json
from pathlib import Path


class Suscripcion:
    PRECIOS = {"basico": 9.99, "pro": 24.99}

    def __init__(self, cliente, plan, meses_activos=0):
        if plan not in self.PRECIOS:
            raise ValueError(f"plan desconocido: {plan}")
        self.cliente = cliente
        self.plan = plan
        self.meses_activos = meses_activos

    def cobro_mensual(self):
        precio = self.PRECIOS[self.plan]
        if self.meses_activos >= 12:
            precio *= 0.85                       # lealtad: 15 % desde el año
        return round(precio, 2)

    def a_dict(self):
        return {"cliente": self.cliente, "plan": self.plan, "meses_activos": self.meses_activos}


def cargar(ruta):
    try:
        datos = json.loads(Path(ruta).read_text())
    except FileNotFoundError:
        return []
    return [Suscripcion(d["cliente"], d["plan"], d["meses_activos"]) for d in datos]


Path("subs.json").write_text(json.dumps([
    {"cliente": "Ana", "plan": "pro", "meses_activos": 14},
    {"cliente": "Luis", "plan": "basico", "meses_activos": 3},
    {"cliente": "Eva", "plan": "pro", "meses_activos": 2}]))

subs = cargar("subs.json")
ingreso = sum(s.cobro_mensual() for s in subs)
por_plan = {}
for s in subs:
    por_plan[s.plan] = por_plan.get(s.plan, 0) + 1
print(f"Ingreso mensual: ${ingreso:.2f}")
print("Clientes por plan:", por_plan)
print("Sin archivo:", cargar("no_existe.json"))
Ingreso mensual: $56.22
Clientes por plan: {'pro': 2, 'basico': 1}
Sin archivo: []

P2 · La misma clase, en C# (S10 + S11)

traducción de clase · ★★★

Traduce Suscripcion y el cálculo del ingreso a C#. Usa propiedades de solo lectura, decimal y List<Suscripcion>. El resultado debe ser idéntico al de Python.

Tu programa debe cumplir estos casos de prueba:

DatoEsperado
Ingreso mensual56.22 (igual que Python)
new Suscripcion("X", "gold", 1)ArgumentException
Pista

raise ValueError → throw new ArgumentException; @property → { get; }; lista → List<T>; el operador ternario reemplaza el diccionario de precios.

Solución
var subs = new List<Suscripcion>
{
    new Suscripcion("Ana", "pro", 14),
    new Suscripcion("Luis", "basico", 3),
    new Suscripcion("Eva", "pro", 2),
};
decimal ingreso = 0;
foreach (var s in subs) ingreso += s.CobroMensual();
Console.WriteLine($"Ingreso mensual: {ingreso:F2}");


public class Suscripcion
{
    public string Cliente { get; }
    public string Plan { get; }
    public int MesesActivos { get; }

    public Suscripcion(string cliente, string plan, int mesesActivos)
    {
        if (plan != "basico" && plan != "pro")
            throw new ArgumentException($"plan desconocido: {plan}");
        Cliente = cliente;
        Plan = plan;
        MesesActivos = mesesActivos;
    }

    public decimal CobroMensual()
    {
        decimal precio = Plan == "pro" ? 24.99m : 9.99m;
        if (MesesActivos >= 12) precio *= 0.85m;
        return Math.Round(precio, 2, MidpointRounding.AwayFromZero);
    }
}
Ingreso mensual: 56.22

Verificación: 24.99 × 0.85 = 21.2415 → 21.24; 21.24 + 9.99 + 24.99 = 56.22 ✔ en ambos lenguajes.

Estrategia para el Final

Durante el examen
  • Separa mentalmente las preguntas de Python y las de C#: antes de responder, pregúntate “¿en qué lenguaje estoy?” (división entera, True vs true, ;).
  • En C#, escribe primero los tipos de cada variable: evita la mitad de los errores.
  • En problemas de objetos: lista atributos, métodos y la regla que se protege antes de escribir.
  • Traza en papel. Prueba con un caso normal y uno de frontera.
